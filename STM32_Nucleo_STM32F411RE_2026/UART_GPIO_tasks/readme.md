**Задание, которому соответсвует код:**
Имитация «экстренного события» на борту робота:
Пока кнопка не нажата — система работает в штатном режиме: LED мигает медленно, UART шлёт телеметрию.
Пока кнопка удерживается — задача светодиода мгновенно повышает приоритет и переходит в «панический» режим: LED мигает с периодом 50 мс.
При отпускании кнопки — приоритеты и период мигания возвращаются к штатным значениям.
Намеренно использован HAL_Delay для иметации задачи с блокировкой. С параметром use_TIME_SLICING 1 две задачи: UART и мигание уживаются, в вытесняющем режиме без квантования времени когда диод мигает, телеметрия не приходит.

Платформа: Nucleo STM32F411RE, Putty для проверки телеметрии UART по COM3 порту.
LED (LD2) - PA5
Кнопка (B1)	- PC13
UART - USART2
